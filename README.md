# DSA_Practice 🧠

A collection of Data Structures and Algorithms practice problems implemented in **Java**.

## 📁 Repository Structure

DSA_Practice/
├── Arrays/
├── AllOcc.java
├── BinarySearch.java
├── DeleteArray.java
├── FrequencyCount.java
├── IDU.java
├── InsertArray.java
├── LastFirst.java
├── LinearSearch.java
├── MinMaxArray.java
├── OddEven.java
├── PrintElements.java
└── PrintReverse.java

## 📚 Topics Covered

### Arrays
| File | Description |
|------|-------------|
| AllOcc.java | Find all occurrences of an element |
| BinarySearch.java | Binary Search algorithm |
| DeleteArray.java | Delete an element from array |
| FrequencyCount.java | Count frequency of elements |
| IDU.java | Insert, Delete, Update operations |
| InsertArray.java | Insert element into array |
| LastFirst.java | Last and First occurrence of element |
| LinearSearch.java | Linear Search algorithm |
| MinMaxArray.java | Find minimum and maximum in array |
| OddEven.java | Separate odd and even numbers |
| PrintElements.java | Print all array elements |
| PrintReverse.java | Print array in reverse order |

## 🚀 How to Run

1. Clone the repository
   git clone https://github.com/aditi00223/DSA_Practice.git
   cd DSA_Practice

2. Compile a Java file
   javac FileName.java

3. Run the program
   java FileName

## 🛠️ Prerequisites

- Java JDK 8 or above
- Any IDE (VS Code, IntelliJ IDEA, Eclipse) or terminal
